# RE:SOURCE room design preview

This is an isolated visual/gameplay variant. The original project at the RE:SOURCE folder root stays unchanged. The opening story, Day 0 ship tutorial, and seven-day resource simulation are carried over; the lunar base is presented as a warm, room-based top-down pixel prototype.

## Preview on this computer

From `C:\Users\Hp\Desktop\astra\design-preview`, run:

```powershell
npm run dev
```

Open [http://localhost:3001](http://localhost:3001). This local setup uses the existing dependencies in the parent RE:SOURCE project. To install the preview independently, run `npm install` inside this folder and change the scripts to `next dev -p 3001`, `next build`, and `eslint src`.

The prototype continues to use the existing provisional RE:SOURCE values and daily rules. It is for testing parameters and is not NASA-validated.
